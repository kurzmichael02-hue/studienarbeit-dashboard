# Wireframes

Erster Entwurf der Oberfläche als klickbare HTML-Vorschau: `mockups.html` (im Browser öffnen, kein Server nötig). Das ist ein Entwurf zur Orientierung für Schayans Frontend, nicht final.

Grundidee: die Startseite hat zwei Modi. "Heute" zeigt was gerade anliegt (fällige Vokabeln, tägliches Quiz, nächste Reise), "Entdecken" ist ein Kachel-Raster mit allen Bereichen. Alles läuft lokal, Profil-Auswahl statt Login mit Account.

## Screens in `mockups.html`
Allgemein:
- Login / Profil-Auswahl
- Startseite "Heute"
- Startseite "Entdecken" (Kacheln)
- Einstellungen
- Notizen

Reise:
- Reisen (Liste)
- Reise-Detail (Tagesplan)
- Neue Reise (Formular)
- Aktivität hinzufügen

Sprache:
- Sprache wählen (Russisch, Japanisch, Koreanisch)
- Vokabeltrainer (Karte umdrehen)
- Quiz (Frage) und Quiz-Ergebnis
- Fortschritt
- Schriftsystem (z.B. Hiragana)
- Rangliste (lokaler Highscore)
