# Wireframes (Frontend)

Verantwortlich: Schayan. Stand: zu erstellen. Grundlage: Use Cases (`docs/konzept/use-cases.md`) + Anforderungen.

Ziel: pro Haupt-Seite eine Skizze, wie die Oberfläche aussieht (welche Listen, Buttons, Felder wo). Werkzeug frei wählbar: draw.io, Figma, oder auf Papier und abfotografieren.

## Seiten, die skizziert werden
- Startseite / Übersicht (Einstieg: Reise oder Sprache)
- Reise-Übersicht + Reise anlegen
- Tagesplan
- Packliste
- Budget / Ausgaben
- Notizen
- Vokabel-Lernseite
- Reisephrasen nach Situation (Flughafen, Restaurant, Taxi)
- Lernfortschritt

## Hinweise
- Schlicht halten, passend zu Bootstrap (Standard-Komponenten)
- Offline-tauglich denken (keine Online-only-Elemente)
- Nah an den Anforderungen bleiben (Muss-Funktionen zuerst)

## Offen
- Skizzen erstellen und hier ablegen (als Bilder, oder Unterordner anlegen)
